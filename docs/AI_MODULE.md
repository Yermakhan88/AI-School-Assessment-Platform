# AI Module

## Purpose

The AI module automatically evaluates uploaded homework.

---

## Workflow

Student

↓

Upload Homework

↓

Submission

↓

Read File

↓

Load Prompt

↓

OpenAI Responses API

↓

Structured Output

↓

AI Review

↓

Teacher Review

↓

Final Grade

---

## Supported File Types

- Python (.py)
- Text (.txt)
- Markdown (.md)

Future

- PDF
- DOCX
- OCR

---

## Prompt Engine

Prompts are stored as Markdown files.

Examples

- python.md
- essay.md
- sql.md

This allows teachers to modify evaluation criteria without changing application code.

---

## AI Output

The AI returns structured assessment.

Fields

- score
- feedback
- strengths
- weaknesses
- recommendations
