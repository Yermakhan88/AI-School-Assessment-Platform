# AI School Platform Rules

1. AI never replaces the teacher.

2. Teacher always makes the final decision.

3. No feature is implemented without approved UX.

4. Every Sprint ends with a working module.

5. No duplicate components.

6. Reuse before creating new.

7. Business logic never lives inside UI.

8. Features are isolated.

9. Every module must be demo-ready.

10. Build products, not pages.
